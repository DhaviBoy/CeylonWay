# 🌍 CeylonWay

CeylonWay is a modern tourism web platform designed to help travelers explore Sri Lanka, discover unique destinations, and book accommodations such as hotels and villas through a simple and user-friendly digital experience.

---

## ✨ Features

- 🗺️ Explore popular and hidden destinations across Sri Lanka  
- 🏨 Discover and book hotels and villas  
- 🔍 Easy navigation with a clean and modern UI  
- 📱 Fully responsive design for all devices  
- ⚡ Fast and smooth user experience
